A cheap, UK-only survey tool -- enter a brand, and Atlas breaks down its catalog by category, showing each category's real Keepa category ID. Use it to find the ID you need for an Exclusion, a Signal Query, or the category filter on the Discovery page -- those all need a real Keepa category ID, which isn't normally visible anywhere else in Atlas.

Surveys up to 500 ASINs per brand (default 100 -- raise "Max ASINs to survey" for a fuller picture of a large brand's catalog). Shows 3 sample titles per category so you can sanity-check that a category actually contains what you'd expect.

This only costs a UK-only Keepa lookup per ASIN surveyed -- no EU marketplace tokens spent here at all, so it's safe to run freely even when your token budget is tight.
