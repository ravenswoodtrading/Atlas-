Saved Keepa searches

Back to Signals
A saved search is a Keepa Product Finder query Atlas can re-run. Stock-out and Ceiling cleared run automatically every 2 hours; Price spike is Run now only. Their results appear on the Signals page.
EU price drop looks at one EU marketplace for products whose price has just fallen, checks prices for free first, then runs the survivors through the full scan. Anything worth buying lands in the Review Queue, and each run is summarised under Recent runs below. It is Run now only and costs roughly 12 Keepa tokens per candidate scanned.
Add a search. For Stock-out/Price spike you can optionally restrict to UK Keepa categories (comma-separated IDs, see the Categories page). For EU price drop the category must be that marketplace's own Keepa category ID -- pick a preset or enter one.
Only DE has been run so far; FR/ES/IT are untried.
Caps token spend per run.
Demand in that marketplace, a weak proxy for UK demand.
Before any Keepa spend, products Amazon says this account can't list (approval required / not eligible) are dropped, and so are products whose title names a mains-plug device (chargers, routers, monitors, kitchen appliances, power tools), since EU units can arrive with an EU plug.
