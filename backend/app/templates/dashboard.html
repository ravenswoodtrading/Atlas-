The Dashboard is a snapshot, not a to-do list -- for actual work queues see Review Queue and Lead Queue.

The top row
  • Products scanned is an all-time count across every scan ever run, most-recent-scan-per-ASIN only (re-scanning something doesn't count it twice). Hover it for how many of those have any profit margin at all -- that's a much lower bar than "worth buying", which is what the tiles below actually track.
  • Keepa tokens remaining comes straight from Keepa's own API and turns red under 50. Every scan, lookup, and background queue item spends tokens -- if this runs out, scans silently stop returning useful data until it refills.
  • Marked BUY / CONSIDER this week are scoped to the last 7 days, unlike the old all-time counts this replaced -- an all-time count only ever goes up and stops being useful for "is anything new happening", which is what this tile is for.
The second row
  • Scan Queue health shows how many brands are queued for continuous background scanning and roughly how often each gets revisited -- see Scan Queue to add or remove brands.
  • New competitor listings (24h) counts newly-detected competitor offers in the last day -- see Competitors for details on any of them.
  • Gated opportunities worth chasing counts gated-brand products that price out well despite being blocked from purchase right now -- see Gated Opportunities for the full case on whether ungating is worth pursuing.
The third row
  • OA Source Discovery counts priced candidates that weren't strong enough to auto-add to the Review Queue -- these need your judgment call (keep, swap in a different retailer, or move on). Also warns if the last run had to stop early to protect your SerpApi search quota.
  • New Signals counts undismissed stock-out/price-spike matches from your Signal Queries -- see Signals.
Today's activity / What's automated next

Today's activity counts real work Atlas has done since UTC midnight -- brand searches (Discovery, manual or via Scan Queue), competitor checks, replen/watchlist rechecks, signal checks, OA Discovery runs, and leads analyzed. This started tracking on 2026-08-19, so it reads 0 for anything that happened before then -- there's no history to backfill.
What's automated next shows when each background scheduler last actually ran and roughly when it's next due, so you can tell a stalled process (stuck on "last ran" from hours ago, well past its usual cadence) from one that's simply between ticks. Lead analysis runs every ~30 seconds, so it's shown as "continuous" rather than a literal countdown.

The alerts below

The Review Queue alert and the VA/manual-verdict alert only appear when there's something in them. The Review Queue count is read directly from what Review Queue itself would show you right now -- star buys (confirmed sales + 25%+ ROI), BUY recommendations, PEAK (risky) leads that clear the stricter 35% ROI/65 score bar, and buyable competitor finds -- so this number and that page can never disagree. There's no separate "reset" for it any more: it naturally goes to zero as you review things, and a small (or empty) queue just means nothing right now clears Atlas's bar for "worth pursuing" -- see the glossary for the exact star-buy rule.
